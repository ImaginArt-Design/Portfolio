## Overview
This project is built purely with HTML, CSS, and JavaScript. It serves as a single-page portfolio with glassmorphism aesthetics and smooth scroll transitions, tailored to present design works elegantly without unnecessary clutter or external libraries.

## Design Highlights
- **Color Palette**: Dark (`#2D2D2D`), Beige (`#D7C9AE`), Cream (`#E9E0D2`), and Brown (`#A68763`)
- **Typography**: Google Font `Outfit` for a clean, modern aesthetic.
- **Micro-interactions**: Hover effects on cards, nav-links underline expansion, dynamic form submission button, smooth fading elements.
- **Glassmorphism**: Elegant translucent UI components providing depth and an up-to-date modern feel.
- **Responsive**: Mobile-first architecture with custom hamburger menu implementation.

## File Structure
- `index.html`: Contains the document outline divided into semantic `<section>` blocks.
- `style.css`: All styling separated logically with custom CSS variables (`:root`).
- `script.js`: Handles data population for skills and project previews to keep HTML clean, as well as Intersection Observers for animation.
- `README.md`: Project documentation.

## Deployment
This project is completely static and ready to be deployed instantly on Netlify, GitHub Pages, or Vercel:
1. Drag and drop the folder containing these 4 files into your Netlify dashboard.
2. The site will deploy instantly.
3. No build steps or packaging required.
